# 首版需求

## 工作台

- Linux 桌面版启动时最大化并保留系统标题栏。按 F11 或点击工作台右上角的按钮可最大化或还原窗口。侧栏可以新建、打开、重命名和删除笔记与画布。
- 桌面版支持 Ctrl 加号放大整个界面、Ctrl 减号缩小、Ctrl 0 恢复原大小。
- 首次启动打开可编辑、可删除的示例画布。示例含一个带代码块的笔记卡片、简短排查记录和手绘标注。再次启动恢复上次打开的条目与画布视口。
- 界面使用暖白背景、浅灰边线和少量墨绿色。正文清晰易读，代码使用等宽字体。浏览器预览可用于审阅 1440×900 和 1024×768 两种桌面尺寸。

## 笔记和画布

- 新建空白笔记，直接编辑标题、段落、粗体、列表、链接、行内代码和带语言高亮的代码块。
- 选择本地 Markdown 文件创建笔记，或将文件导入画布作为独立可编辑卡片。画布支持选择文件后放置，也支持拖放。
- 新建空白画布，可平移、缩放。选择文本工具后点一下就能放置文本框。文本框和笔记卡片可编辑、拖动和删除。
- 从已有笔记中选择一篇放上画布，卡片取得当时的标题和正文副本。卡片中的正文可用同一套可视化编辑器继续修改。
- 用画笔在任意位置手绘。每次拖动绘制一笔，工具栏可以撤销最近一笔。
- 正式应用自动保存工作区。保存失败可看到提示并重试，当前编辑内容留在界面上。

## 验收

| 场景 | 通过条件 |
| --- | --- |
| 安装和首次启动 | Linux 可从 `.deb` 安装，启动时窗口最大化，示例可编辑和删除，F11 可最大化或还原窗口。 |
| 界面缩放 | 快捷键缩放整个应用，Ctrl 0 恢复到 100%，画布原有缩放比例保留。 |
| 编辑笔记 | 能创建笔记、直接编辑各基础格式，切换页面或重启后内容可恢复。 |
| 导入 Markdown | UTF-8 文件可从侧栏导入成笔记，也可从画布工具栏选择或直接拖入。标题、列表和代码块可编辑，失败有提示，重启可恢复。 |
| 使用画布 | 能放置卡片和文本框，拖动、删除和编辑，能平移缩放、手绘和撤销一笔。 |
| 卡片副本 | 修改卡片标题或正文后，独立笔记仍保有原内容。两张复制自同一笔记的卡片可以各自编辑。 |
| 恢复工作区 | 重启后恢复当前条目、视口、卡片位置、文本和笔迹。删除示例后再次启动，示例仍为已删除状态。 |
