# 思维导图图片导出

## 怎么用

打开画布底部「思维导图 → 导出 PNG」。图片包含当前画布的全部导图节点、连线和连线名称，使用画布名称作为文件名。

## 代码怎么走

页面把导图数据传给导出函数。函数使用导图的边界、连线端点和节点配色绘制图片，再返回 PNG 给页面下载。较大的导图会按比例缩小，图片仍包含画布上所有节点。

| 文件或入口 | 调用方 | 输入与效果 |
| --- | --- | --- |
| `index.ts` | `CanvasView` | 导出页面使用的图片生成入口。 |
| `renderMindMapPng(map)`，`renderMindMapPng.ts` | `CanvasView` | 接收导图节点和连线，返回 PNG 文件内容。 |
