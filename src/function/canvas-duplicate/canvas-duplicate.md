# 复制画布

## 怎么用

在侧栏打开画布旁的更多菜单，选择「复制画布」。应用会打开新建的副本，带上原来画布中的卡片、文本框、笔迹和思维导图。副本可以独立编辑。

## 代码怎么走

工作台取出当前画布和已有的标题，调用复制函数。函数复制正文与坐标，为新画布、对象、节点和连线分配 ID，再用新节点 ID 恢复连线。

| 文件或入口 | 调用方 | 输入与效果 |
| --- | --- | --- |
| `index.ts` | `App` | 导出画布复制入口。 |
| `duplicateCanvas(source, existingTitles, nextId?, title?)`，`duplicateCanvas.ts` | `App` | 接收画布、现有标题、可选 ID 生成函数和副本标题，返回独立副本。普通复制和翻译导图副本共用此函数。 |
